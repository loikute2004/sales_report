
# MOSCOW PRIORITIZATION & MVP

## 1. Must Have

- Đăng nhập và phân quyền.
- Tạo ticket.
- Xem danh sách ticket.
- Xem chi tiết ticket.
- Gán ticket cho nhân viên.
- Cập nhật trạng thái ticket.

## 2. Should Have

- Bình luận ticket.
- Upload file đính kèm.
- Gửi email thông báo.

## 3. Could Have

- Dashboard thống kê.
- Xuất báo cáo Excel.

## 4. Won't Have

- Chat trực tiếp.
- Ứng dụng di động.
- Tích hợp tổng đài.

## 5. Phạm vi MVP

MVP tập trung vào quy trình:

Đăng nhập
    -> Tạo ticket
    -> Xem ticket
    -> Gán người xử lý
    -> Cập nhật trạng thái

## 6. Kết luận

Phiên bản MVP tập trung vào quy trình tiếp nhận
và xử lý yêu cầu hỗ trợ cơ bản.

Các chức năng bổ sung sẽ được xem xét
trong những giai đoạn tiếp theo.
